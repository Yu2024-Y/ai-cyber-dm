# User Story 清单（需求拆解）

> 项目：AI 赛博 DM 与无限跑团引擎
> 说明：核心需求拆解为用户故事，遵循 INVEST 原则；核心故事（US02、US03）配完整 6 图建模。

---

## 用户故事总览

| US | 标题 | 优先级 | SP | 一句话描述 |
|----|------|:---:|:---:|-----------|
| US01 | 创建与加载跑团会话 | P0 | 3 | 玩家新建或加载一个跑团会话（含角色设定） |
| US02 | 玩家指令触发 DM 剧情生成 | P0 | 5 | 玩家自由输入指令，DM 生成剧情并推进（核心，6 图） |
| US03 | 骰子检定判定 | P0 | 5 | 输入检定指令，系统掷骰判定成败，影响剧情（核心，6 图） |
| US04 | 上下文记忆管理 | P0 | 3 | 长对话不失忆，滑动窗口 + 摘要压缩 |
| US05 | 会话历史持久化与断点续玩 | P0 | 3 | 会话状态存入数据库，可恢复继续 |
| US06 | 场景卡与角色卡生成 | P1 | 5 | 剧情触发时异步生成场景图 / NPC 画像 |
| US07 | 剧情语音播报 | P1 | 2 | 关键剧情用 edge-tts 合成语音 |
| US08 | 输入校验与防护 | P0 | 3 | 输入长度/内容校验、Prompt 注入防护 |

## Sprint 对应

| Sprint | 覆盖 US |
|--------|---------|
| Sprint 1（骨架） | 需求拆解、后端初始化、数据层（US01/US05 的基础） |
| Sprint 2（MVP） | US01、US02、US03、US04、US05 |
| Sprint 3（体验/防御） | US06、US07、US08、UI/SSE 优化 |
| Sprint 4（发布） | CI/CD、Docker、评测 |
