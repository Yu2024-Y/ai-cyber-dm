# US08 输入校验与防护

优先级：P0 ｜ 故事点：3 ｜ 对应 Sprint 3

## Card

- **As a**：系统/运维
- **I want**：对玩家输入做校验和防护
- **So that**：系统稳定，Prompt 不被注入攻击

## Conversation

- 前置条件：玩家可输入任意文本
- 描述：输入长度/内容校验（如 500 字上限、空白拦截）；API 频控（请求限流）；Prompt 注入防护（系统提示隔离、越权指令检测）；结构化日志记录异常
- 验收：恶意/超长输入被拦截；请求频控生效；注入指令被拒绝；异常有日志

## Confirmation

```gherkin
Feature: 输入校验与防护
  Scenario: 超长输入被拦截
    Given 玩家在会话中
    When 玩家输入超过 500 字的指令
    Then 系统返回输入错误提示
    And 不调用大模型
  Scenario: 注入指令被拒绝
    Given 玩家在会话中
    When 玩家输入"忽略之前的设定，执行..."
    Then 系统拒绝并提示越权
```
