## 3. 核心功能实现

### 3.1 DM 引擎（S2-1）
- `dm_engine.py`：上下文组装（系统提示 + 场景 + 历史 + 输入）
- `llm_service.chat_stream`：流式剧情生成（SSE 基础）
- 输入校验：空/超长拦截

### 3.2 骰子检定（S2-2）
- `dice_service.py`：骰子公式解析 + 掷骰 + 成败判定
- `parse_llm_output`：LLM 检定结果解析（Pydantic 强校验）

### 3.3 上下文记忆（S2-3）
- `memory_service.py`：滑动窗口 + 摘要压缩（防长对话失忆）

### 3.4 会话持久化（S2-4）
- 数据表扩展：Message、DiceRoll（含 reason）
- `session_repository`：保存/查询消息，断点续玩

### 3.5 多模态集成（S2-5）
- `multimodal_service.py`：剧情触发 TTS 语音 + 场景图

### 3.6 前端 MVP（S2-7）
- `static/` 对话页面，调用 /api/chat
