## 3. 实现内容

### 3.1 SSE 流式响应（S3-1）
- 前端 `app.js` 改用 fetch reader 流式读取，剧情逐段显示（打字机效果）
- 后端 /api/chat 返回 text/event-stream

### 3.2 异步生图队列（S3-2）
- `image_queue.py`：异步队列 + 限流 + 指数退避重试
- 状态机：PENDING → RUNNING → SUCCESS / FAILED（重试耗尽降级占位图）

### 3.3 Prompt 注入防护（S3-3）
- `security_service.py`：输入校验（空/超长）+ 越权指令检测
- 防护"忽略设定/扮演/系统提示"等注入

### 3.4 API 频控与重试（S3-4）
- `rate_limiter.py`：滑动窗口限流 + retry_with_backoff

### 3.5 结构化日志（S3-5）
- `logging_setup.py`：JSON 格式日志，含 session_id 等关键字段

### 3.6 剧情分支树（S3-6）
- `story_tree.py`：记录剧情节点，输出嵌套结构供可视化
